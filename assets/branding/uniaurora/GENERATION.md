# Registro de geração — UniAurora v0.1

Execução: ferramenta de geração de imagens disponível na sessão, com referências locais. Sem uso de uma API externa configurada pelo mantenedor.

Referências de família visual: `../aurora-cyber-range/aurora-cyber-range-logo-landscape.png` e `../aurora-cyber-range/aurora-cyber-range-symbol.png`.

Direção solicitada: criar uma identidade similar para UniAurora, seguindo a família visual e as cores do Aurora Cyber Range. O nome institucional utilizado na proposta é “UNIVERSIDADE AURORA”.

## Construção da referência inicial

Foi proposta uma assinatura horizontal com um A angular e faixa de aurora em ciano, azul e violeta; lettering “UniAurora” em azul escuro e subtítulo “UNIVERSIDADE AURORA”. A referência inicial serviu apenas à iteração visual. A geração inicial não produziu canal alfa utilizável; a entrega foi ajustada para duas versões com fundos incorporados, explicitamente identificadas como opacas.

Arquivo final: `uniaurora-logo-light-v0.1.png`.
